# 改稿标准 v2：瘦身 + 引用只放能证明这条的

（依据 2026-10-09 老板反馈：对照《高性价比人生指南》，「说人话」「收益」都是一句话/一段；我们现在的内容太多；引用尤其前中后台那类，引了一堆宏观数据，跟本条的论点无关，证明不了任何事。）

## 一、每条的结构（从「多段小标题」压成四块）

| 块 | 写法 | 长度上限 |
| --- | --- | --- |
| 标题 | 那句建议本身 | 不设限 |
| 说人话 | **一段话讲完**，开门见结论，带一个能核对的数字（没有官方数字就写做法本身，不硬塞） | ≤120 字 |
| 为什么 / 怎么做 | **最多 3 条短句**，每条 ≤40 字；不再分「一、二、三」多个小标题 | ≤150 字 |
| 来源 | **只放能直接证明本条论点的**，1–3 条；没有就直接写「未找到直接相关的官方数据」 | — |
| 限制与争议 | ≤2 句，说清哪种情况下不成立 | ≤120 字 |
| **整条** | | **≤800 字**（对照《人生指南》中位数 922 字） |

现有的「三族岗位的典型部门和边界」「为什么先分族，而不是先比工资」这类中间小标题**全部撤掉**，内容压进「说人话」和「为什么」两段。

## 二、引用标准（老板这次点名的）

1. **来源必须能直接证明本条论点**。做不到就不引——宁缺毋滥。
2. **宏观数据只能用在宏观结论上**：分行业平均工资、就业人数这类统计，只能支撑「哪个行业工资高/在收缩」这类结论；用来支撑「怎么判断自己在哪条路上」这种操作建议，就是无效引用。
3. 反面例子（本次被点名）：第 5 章第 1 条讲「怎么判断自己在前台还是中台」，却引了国家统计局 2025 年平均工资和解读 → 跟论点无关，**删掉**，改在限制里说明「前台/中台/后台是公司内部叫法，官方统计没有对应口径」。
4. 反面例子二：第 2 章第 8 条把「2024 年全国查处 13.7 万件、追回 86.5 亿元」放在说人话里当论据 → 这是全国总量，不能证明「你遇到这类公司该怎么判断」，**删掉**，只留能直接支撑的（加班费 1.5/2/3 倍、逾期不付加付 50%–100%）。
5. 法条、官方统计、权威报告照旧要带链接和年份。

## 三、试改样本（请先看这两条，确认后再全书铺开）

### 样本 A：第 5 章第 1 条（原 978 字 → 改后 396 字）

**改前**：说人话一段（150 字）+「三族岗位的典型部门和边界」+「为什么先分族，而不是先比工资」+「怎么用」四个分段；来源引国家统计局平均工资与解读两条。

**改后**：

> **说人话：** 公司里的岗位分三族：前台直接带来收入，中台用专业能力支持前台，后台做行政和基础服务。判断办法很简单——你所在部门的业绩翻倍，公司收入会不会跟着翻倍：会，是前台；有影响但不直接，是中台；几乎没关系，是后台。
>
> **为什么这么分：** 三族的收入上限、波动、可替代性、能干到多少岁都不一样，混在一起比会失真；同一个岗位在 A 公司算前台、在 B 公司可能算中台，按「离钱远近」判断即可，不必纠结名称。
>
> **来源：** 未找到直接相关的官方数据。前台、中台、后台是公司内部叫法，官方统计里没有对应口径。
>
> **限制与争议：** 这套分法是经验框架，只用来给自己定位，不预测个人发展；具体值不值得做，还要看行业周期和公司经营状况。

### 样本 B：第 2 章第 8 条（原 2543 字 → 改后 690 字）

**改前**：七个小标题分段（工资拖欠 / 社保 / 加班 / 收钱 / 亲属把持 / 违法业务 / 招聘失实）+ 已经进去了怎么办；说人话里带「13.7 万件、86.5 亿元、285.4 亿元」等全国总量。

**改后**：

> **说人话：** 工资不准时、社保按最低基数缴或干脆不缴、长期强制加班不给钱、入职先收钱、关键岗位只给亲属、业务本身违法、招聘信息跟实际不符——这七类不是小毛病，是会直接动到你的钱、健康和职业记录，遇到先排除。
>
> **为什么这七类要一票否决：** 工资发不出来通常说明现金流已经出问题，偶发一次可以观察，连续两次就不必等；社保按最低基数缴，养老金和医保报销额度都会低一截，依法缴纳是义务不是恩惠；加班费按 1.5 倍、2 倍、3 倍三档算，不给可以投诉，逾期不付还要加付 50% 到 100%；入职前先收钱（招聘转培训、培训贷、押金、服装费）是典型招聘套路；关键岗位由老板亲属把持，可验证的判断是有没有非亲属做到中高层；业务本身违法或处在灰色地带，出事时收入和职业记录都受影响；招聘信息与实际严重不符的，先查工商信息和员工评价。
>
> **已经进去了怎么办：** 试用期内发现不对尽早止损；被欠薪或违法辞退走劳动监察投诉和劳动仲裁，两条路都不收费；离职前后把合同、工资条、考勤、聊天记录各留一份。
>
> **来源：** 录用钱款类风险提示（人社部等五部门）；工资支付与加班费条款（劳动法第四十一条、第五十条）；工商与执行信息在「国家企业信用信息公示系统」「中国执行信息公开网」自查，需在浏览器打开。
>
> **限制与争议：** 一个信号就否决可能误判——涉及钱、法律和人身安全的四类可以一票否决，亲属把持和招聘信息失实这两类建议再看两条信息；社保按最低基数缴不必然要立刻走人，但要问清什么时候补齐、写不写进合同。

## 五、字数怎么用（2026-10-09 老板补充，优先于上面的数字）

**字数不是硬指标，不要为省而省。**判断标准只有一条：**读者能不能花最小的精力，一遍读懂、照着做**。

- 800 字、120 字这些数字是「提醒你检查」的尺子，不是必须压到的靶子。某条确实需要 900 字才说得清，就让它 900 字。
- 撤中间小标题、合并分段，目的是让阅读顺、不折腾，不是为了变短。
- 反过来，如果一条被压得丢了关键步骤、适用条件、金额口径，那是改坏了，要补回来。
- 质检脚本报「超 800 字」只是提示，不是错误；真要判，就按「外行读一遍能不能照做」来判。
