## 三、写作口径（沿用改稿标准 v2，逐条核对）

- 四块结构：`说人话：` / `为什么 / 怎么做：` / `来源：` / `限制与争议：`，加粗小标题与正文同段，块间空一行。
- 条首标签行照现有格式：是否花钱｜时间成本｜精力成本｜性价比｜证据等级（另有口径标签）。
- 来源：**不限于官方统计**——同行评议论文、学术书籍、权威期刊/年鉴、权威机构报告、法条与指导案例都算；**引文必须真实可核对**（作者/年份/标题/期刊或出版社/链接），一条都不能编；确实找不到的直接写「无」，并在「限制与争议」里注明属经验判断。
- 字数：说清楚优先，不为省而省；「说人话」≤120 字是提醒，条目 ≤800 字是提示不是错误。
- 禁用「不是 X，是 Y」对比句式；禁用口号与绝对化承诺；不写推荐、不预测收益。
- 中文引号「」；列表一条一行；不出现连续空行。
