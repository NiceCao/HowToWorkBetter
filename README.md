# 高性价比工作指南

一本写给普通打工人的工作指南。从选行业、谈薪水，到入职生存、晋升转型、被裁维权，一共 **50 章、416 条建议**。

每条建议都写成一句能直接照做的话，并且带四样东西：

- **说人话**：这条到底在讲什么，一句话结论；
- **为什么**：背后的规则、账或机制；
- **来源**：官方统计、法规原文、权威报告的链接，能点回去核对；
- **限制与争议**：这条在什么情况下不成立、数据是哪一年的、哪里有争议。

条目按**性价比**分三档（极高 / 高 / 一般），并标注**证据等级**（A 有硬数据、B 有间接支撑、C 属经验做法）。

## 从哪开始读

别从第 1 章顺读。先打开 **[怎么用这本书（导航页）](index.html)**：

- 按「**你现在在哪一步**」——还没入行 / 拿到 offer / 入职前 90 天 / 站稳的 1–3 年 / 开始带人 / 遇到风险 / 长期与兜底；
- 按「**你是做什么的**」——销售市场商务 / 产品技术运营 / HR 财务法务行政 / 管理岗 / 体制内 / 应届生 / 蓝领产线；
- 或者直接在导航页里**搜关键词**（如「加班」「社保」「被裁」「提成」），跳到你关心的那一条。

## 来源与免责

书里的数字来自官方统计（国家统计局、人社部、最高法等）、法规原文与权威报告，每条都标了来源，尽量给可打开的原文链接。少数站点的链接对脚本不友好，需在浏览器打开。

所有内容仅供参考，**不构成法律、医疗、投资建议**。金额、时限、比例这类数字以当地主管部门最新规定为准；遇到具体纠纷请咨询专业人士或拨打 12333（人社）、12348（法律援助）。
