第30章 新人生存法则：前两年怎么过

前两年先花在摸清规则、做出产出、处好关系这三件事上，比急着比较工资回报更高。本章八条按这个顺序排：前四条讲入职就把试用期规则、任务标准、提问方式和第一件可交付的作品做扎实，中间三条讲怎么找反馈、怎么看待前两年的工资、以及团队里哪些话和事不要碰，第八条讲第一份工作什么条件下该走、尽量在职找下家。 ---

极高性价比

1.入职第一周向直属领导确认试用期期限、考核标准和转正条件

性价比：极高

成本：钱=0 时间=高 精力=高

口径：职业寿命

证据等级：A

说人话： 试用期最长六个月，试用期工资不得低于同岗位最低档或劳动合同约定工资的80%，这些都是法律硬规定，不靠领导印象。入职第一周把期限、考核标准、转正条件问清楚，用邮件或聊天记录留痕，后面才有依据。

为什么 / 怎么做：

  • 试用期期限按合同长短定：三个月以上不满一年最长一个月，一年以上不满三年最长两个月，三年以上和无固定期限最长六个月
  • 考核项和达标线请直属领导讲清，落到书面或工作群，并确认转正由谁拍板
  • 社保和公积金都在用工之日起三十日内办理登记，转正前就该缴

来源：

  • 全国人大常委会. 中华人民共和国劳动合同法，第十九条试用期期限、第二十条试用期工资、第二十一条试用期解除. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm
  • 全国人大常委会. 中华人民共和国社会保险法，第五十八条自用工之日起三十日内办理社会保险登记. https://www.gov.cn/guoqing/2021-10/29/content_5647616.htm
  • 国务院. 住房公积金管理条例，第十五条自录用之日起三十日内办理缴存登记. https://xzfg.moj.gov.cn/front/law/detail?LawID=1222

限制与争议： 期限和工资是法律下限，公司可以给更短期限、更高工资；第二十一条只限制单位不能随意解除，出现第三十九条情形单位仍可解除。社保关键是看有没有按实际工资足额缴，办了登记和缴足是两回事。

2.接到任务先问清目的、评价标准和交付对象，再动手

性价比：极高

成本：钱=0-少 时间=高 精力=中

口径：职业寿命

证据等级：A

说人话： 新人接到新任务，先别急着打开软件。把目的、评价标准、交付对象问清楚再动手，比闷头做三天再返工省时间；工具是最后一步，够用就行。

为什么 / 怎么做：

  • 先问目的：这件事要解决什么问题、做出来给谁看
  • 再对标准：怎么算做好了、谁说了算、有没有历史模板
  • 最后才定工具：用什么软件、什么格式按要求来，不在技巧上花时间

来源： Locke, E. A., & Latham, G. P. (2002). Building a Practically Useful Theory of Goal Setting and Task Motivation: A 35-Year Odyssey. American Psychologist, 57(9), 705–717. https://med.stanford.edu/content/dam/sm/s-spire/documents/PD.locke-and-latham-retrospective_Paper.pdf

限制与争议： 「先问目的再动手」在需要判断的任务上更适用，标准作业类岗位按要求执行即可，不必事事追问；不同团队对追问的容忍度差别很大。

3.提问前先自查、带上自己的方案，问完把答案记下来

性价比：极高

成本：钱=0 时间=少 精力=低

口径：时间精力 / 职业寿命

证据等级：B

说人话： 提问是新人最高频的动作，也最容易招人烦。三条规矩：先自己查一遍，带上自己的方案，问完记下来别问第二遍。

为什么 / 怎么做：

  • 问之前：先查公司文档、知识库、培训资料，把可能的方案写出来
  • 问的时候：一句话讲清问题，说清背景和想要的结果，对方忙时先约时间
  • 问完之后：把答案记下，同一问题不问第二遍；用了对方办法后反馈结果

来源： 无

限制与争议： 「先自查再提问」的前提是公司有可查的文档，文档缺失时直接问更快；不同团队对提问的容忍度差别很大，策略要分开。 本条属经验判断，无官方统计支持。

4.入职头三个月，把一件小事做到可交付，留下你的第一份作品

性价比：极高

成本：钱=0 时间=高 精力=中

口径：职业寿命 / 收入

证据等级：B

说人话： 领导判断一个新人，看的是你交出来的东西，不是你说过什么。头三个月抓住手头一件小事，做到能直接用的程度，比同时开五个坑更有效。

为什么 / 怎么做：

  • 选一件能做完的小事：数据整理、会议纪要、竞品价格对比
  • 做到可交付：格式统一、结论在前、没有明显错误，交出去不用返工
  • 多做一步：写清你做了什么、结果如何，再附一句建议

来源：

  • 哈佛商业评论（经界面新闻转载）. 最初 90 天很关键：职场新人需要这样传帮带. https://www.jiemian.com/article/469984.html

限制与争议： 该文面向管理者、属入职经验访谈，只能支撑「头三个月很关键」这个方向；「第一个作品」提高被记住的概率，不保证晋升，还要看编制、业务和领导。

高性价比

5.找一个愿意给你反馈的人，定期同步进展并记录建议

性价比：高

成本：钱=0-少 时间=中 精力=低

口径：职业寿命

证据等级：A

说人话： 有人带比自学快，但多数公司没有正式的导师制，好师傅要自己去找、去维护。找的是愿意给你具体反馈的人，不一定是头衔最高的那位。

为什么 / 怎么做：

  • 找谁：愿意点出你哪里对、哪里错，业务熟练又不抢功，和你够得着
  • 怎么处：小事靠近、主动搭把手，教过的很快会用，答应的事按时交付
  • 定期同步：把进展和用了他的方法后的结果告诉他，别有事才出现

来源：

  • 哈佛商业评论（经界面新闻转载）. 最初 90 天很关键：职场新人需要这样传帮带. https://www.jiemian.com/article/469984.html

限制与争议： 该文建议给新人指派导师、让新人随时请教并得到反馈，方向上支持本条；但它面向管理者、是经验访谈而非统计，不能量化证明「有师傅一定比自学快」，导师制在很多公司也只是形式。

6.前两年把成长和可写进履历的成果排在工资前面，但守住最低生活线

性价比：高

成本：钱=少（机会成本） 时间=高 精力=中

口径：职业寿命 / 收入

证据等级：A

说人话： 前两年工资基数低，差几百块对长期收入影响有限，成长速度和能写进履历的成果影响更久。别只盯工资，也别被「年轻人别看重钱」带偏；试用期工资不得低于同岗位最低档或约定工资的80%，先守住这条线和最低生活线。

为什么 / 怎么做：

  • 比工资更该看：有没有人带、能不能接触核心业务、做的事能不能写成项目经历、公司和行业的简历背书
  • 守住底线：工资至少覆盖房租、吃饭和通勤，不靠借债撑
  • 判断真成长还是画饼：看有没有具体的人带、明确的成长路径和能上手的事

来源：

  • 全国人大常委会. 中华人民共和国劳动合同法，第二十条试用期工资下限. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm

限制与争议： 「前两年别在意工资」对经济压力大的人不适用，先保证生活再谈成长；行业差别很大，互联网和金融起薪高、传统行业低，且没有能直接证明「前两年成长优先一定回报更高」的官方数据。

7.在团队里少议论人和事，薪资与评价走正式渠道，分歧留书面记录

性价比：高

成本：钱=0 时间=低 精力=低

口径：职业寿命

证据等级：A

说人话： 新人常踩的坑，多数和「说了不该说的话、卷进不该卷的事」有关。把下面几条当动作清单，能少很多麻烦。

为什么 / 怎么做：

  • 少议论人和事：不在群里、饭桌上评价同事和领导，抱怨找公司外的人说
  • 薪资和评价走正式渠道：不打听同事工资，对考核有异议按公司流程提
  • 不急着站队，挨批先改再解释：新人信息少，先中立干活，被指出问题时先按规定改

来源：

  • 全国人大常委会. 中华人民共和国劳动合同法，第三十九条用人单位可以解除劳动合同的情形. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm

限制与争议： 「少议论」不等于不说话，涉及工作的事实和风险要正常沟通，别把沉默当成安全；严重违反规章制度单位可解除，前提是规章制度合法有效，先把员工手册、考勤和报销这些规则看一遍。

一般性价比

8.第一份工作是走是留，用三条可核对的标准判断，尽量在职找下家

性价比：一般

成本：钱=高（风险成本） 时间=中 精力=中

口径：职业自由 / 收入

证据等级：B

说人话： 想走的时候先分清是被情绪推着走，还是事实到了该走的时候。用可核对的标准判断，尽量在职找好下家再走。

为什么 / 怎么做：

  • 看事实不看情绪：只是累、跟人合不来、觉得活没意思，多半是适应期，给自己几个月再看
  • 这几类是走的信号：公司违法、长期拖欠工资、不缴社保，或领导抢功、甩锅、当众羞辱
  • 走之前先看规则：转正后提前三十日书面通知，试用期内提前三日通知；拿到录用通知再提离职

来源：

  • 全国人大常委会. 中华人民共和国劳动合同法，第三十七条、第三十八条解除劳动合同的条件. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm

限制与争议： 第三十八条给的是劳动者可以解除劳动合同的情形，但认定违法、欠薪需要证据，口头说法不够；干多久走合适行业差异很大，互联网流动快，传统行业和国企更慢，没有能直接套用的官方经验值。

本章小结： 前两年先把规则摸清、把产出做出来、把人处明白。可核对的动作：入职第一周确认试用期期限、考核标准和转正条件；接到任务先问目的、标准和交付对象；提问前先自查、带上方案、问完记录；头三个月做出一件可交付的作品。工资上，前两年以成长为先，试用期工资不得低于相同岗位最低档工资或约定工资的80%且不低于当地最低工资，社保和公积金自用工之日起三十日内就要办理登记。要走的时候先用事实而不是情绪判断，尽量在职找下家。
