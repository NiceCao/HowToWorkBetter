第50章 职场反面清单：这些事千万别做

这一章解决的是：职场里哪些事做了会给自己带来麻烦，以及遇到这些情形时改成怎么做。阅读顺序按性价比分组：第 1 条到第 4 条是极高性价比，涉及抱怨、朋友圈发言、工位摸鱼、当面顶撞领导；第 5 条到第 7 条是高性价比，涉及站队、传闲话、碰公司的钱和物；第 8 条是一般性价比，讲怎么对待新人。 ---

极高性价比

1.别在同事面前抱怨公司和老板，有不满走正式反馈渠道或换环境解决

性价比：极高

成本：钱=0 时间=少 精力=低

口径：职业寿命 / 收入

证据等级：A

说人话： 在同事面前抱怨公司和领导，是最常见、也最容易吃亏的一类话：它会二次传播、容易走样，最后变成别人对你职业态度的判断，影响分配机会、评优和晋升。有不满，走能解决问题的正式渠道，或者换环境。

为什么 / 怎么做：

  • 有具体诉求，和直属领导一对一谈，或以书面形式向人力资源部门反映，把话讲成「问题加建议」。
  • 同事在你面前吐槽时，不接话、不附和、不转述；想发泄，找不在同一家公司的人说。
  • 沟通不动，就把精力放到更新简历、了解外部机会上，用换环境解决。

来源： 能直接对应的是名誉权与劳动合同解除的法律边界：

  • 全国人民代表大会常务委员会（2020年通过，2021年施行）. 中华人民共和国民法典，第一千零二十四条（名誉权）. http://www.mod.gov.cn/gfbw/qwfb/yw_214049/4866121.html?big=fan
  • 全国人民代表大会常务委员会（2007年通过，2012年修正）. 中华人民共和国劳动合同法，第三十九条. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm

限制与争议： 合理的意见反馈和建设性批评是必要的，本条针对的是情绪化抱怨，不是不让你反映问题；抱怨迟早传到当事人耳朵里属常见经验，无权威统计量化概率，名誉权是否成立要个案判断。

2.把朋友圈当公开内容对待：别吐槽公司、别晒摸鱼、别发情绪化内容

性价比：极高

成本：钱=0 时间=极少 精力=极低

口径：职业寿命 / 职业自由

证据等级：A

说人话： 微信里加上同事、领导和客户以后，朋友圈对这些人就是公开的；你随手一发，看的人会当成你的态度。分组、三天可见能降低被看到的概率，但挡不住截图和转发。

为什么 / 怎么做：

  • 发布前先假设它会被领导和客户看到；设置可见时间范围，减少被翻旧账的机会。
  • 别发这几类：吐槽公司领导同事、抱怨工作、晒摸鱼旷工、卷入敏感话题或地域性别攻击。
  • 真想吐槽，发在没有同事和客户的账号，或当面说。

来源： 能直接对应的是隐私权、名誉权与劳动合同解除的法律边界：

  • 全国人民代表大会常务委员会（2020年通过，2021年施行）. 中华人民共和国民法典，第一千零三十二条（隐私权）、第一千零二十四条（名誉权）. http://www.mod.gov.cn/gfbw/qwfb/yw_214049/4866121.html?big=fan
  • 全国人民代表大会常务委员会（2007年通过，2012年修正）. 中华人民共和国劳动合同法，第三十九条. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm

限制与争议： 朋友圈属个人行为，用人单位一般无权干涉，只有内容影响工作、损害名誉时才可能进入制度和法律评价；各地对朋友圈不当言论能否作为解除劳动合同依据的判例不一。

3.上班别在工位公开打游戏、追剧、刷视频，休息控制在不显眼、短时间的范围内

性价比：极高

成本：钱=0 时间=0 精力=0

口径：职业寿命 / 收入

证据等级：B

说人话： 工作时间偶尔走神、短休很正常，真正的问题是在工位上做和工作无关又很显眼的事，还被管理者看到；被抓一次，留下的印象会跟很久。

为什么 / 怎么做：

  • 先按优先级把手上的事做完，走神和休息分散、缩短，别连续刷手机、游戏、视频。
  • 休息离开工位，或看行业资料这类沾业务的低强度事；不用公司设备和网络做私活。
  • 留意边界：办公设备和网络多在公司管理范围内，可能被记录或监控；处理员工信息要遵循合法、正当、必要，限于最小范围。

来源：

  • 全国人民代表大会常务委员会（2021年通过，2021年施行）. 中华人民共和国个人信息保护法，第六条. http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html
  • 全国人民代表大会常务委员会（2007年通过，2012年修正）. 中华人民共和国劳动合同法，第四条、第三十九条. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm

限制与争议： 工作时间做与工作无关的事是否违规、到什么程度算严重，取决于公司制度和岗位性质；监控的合法边界在个案中有争议，「每天高效只有四五小时」无权威统计，本条不引以为据。

4.别当面顶撞领导，有不同意见私下提；涉及违法违规的指令要明确拒绝

性价比：极高

成本：钱=0 时间=少 精力=中

口径：职业寿命 / 收入 / 职业自由

证据等级：A

说人话： 当众顶撞领导，赢的是嘴上，输的是后续；意见可以提，但要选场合、讲方式。唯一要当场硬顶的例外，是对方让你做违法违规的事。

为什么 / 怎么做：

  • 有不同意见私下说，对事不对人，用数据和事实展开；先说目标一致，再讲具体顾虑和替代方案。
  • 涉及违法违规的指令，明确拒绝，并保留书面记录。
  • 劳动合同法第三十二条规定，拒绝违章指挥、强令冒险作业不视为违反劳动合同；人社部、最高法超时加班典型案例明确，拒绝违法超时加班不能据此解除劳动合同。

来源：

  • 全国人民代表大会常务委员会（2007年通过，2012年修正）. 中华人民共和国劳动合同法，第三十二条. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589931971.htm
  • 人力资源社会保障部、最高人民法院（2021）. 超时加班劳动人事争议典型案例（第二批），案例1. https://www.court.gov.cn/zixun/xiangqing/319161.html

限制与争议： 顶撞会被记恨属常见经验，无官方统计；拒绝违章指挥和违法指令受法律保护，但不是所有你不认同的安排都能拒绝，要具体判断。

高性价比

5.别急着站队，把精力放在可核查的业绩和过程留痕上

性价比：高

成本：钱=0 时间=少 精力=中

口径：职业寿命 / 职业自由

证据等级：B

说人话： 有人的地方就有派系；急着选边，等于把职业前途押在你看不透的博弈上。稳妥做法是和各方都保持职业关系，把活干好、把过程留痕，同时保留换环境的退路。

为什么 / 怎么做：

  • 和各部门保持正常的业务往来，不参与私下议论，不做站队表态。
  • 把工作过程留痕：邮件、会议纪要、审批记录，重要沟通留下书面痕迹。
  • 用可核查的业绩说话；环境内耗严重、看不到改善的，早点找外部机会。

来源： 相关的法律依据是《劳动争议调解仲裁法》第六条：

  • 全国人民代表大会常务委员会（2007年通过，2008年施行）. 中华人民共和国劳动争议调解仲裁法，第六条. http://www.npc.gov.cn/c2986/c4488/201905/t20190523_48437.html

限制与争议： 不站队本身也可能被两边边缘化，这是取舍问题，通常比被当枪使、被牵连的代价小；留痕注意方式，正常的邮件、纪要不违规，别把涉密资料对外留存。

6.别传同事闲话，听到八卦不追问、不评论、不转发

性价比：高

成本：钱=0 时间=少 精力=低

口径：职业寿命 / 职业自由

证据等级：B

说人话： 办公室八卦传得快、也传得歪；你传出去的话，最后可能变成对别人的评价甚至攻击，还会拉低你自己的可信度。

为什么 / 怎么做：

  • 听到八卦不追问、不评论、不添油加醋；别人说第三人坏话时，把话题引回工作。
  • 评价别人的话，当面怎么说背后就怎么说；当面不敢说的，背后也别说。

来源：

  • 全国人民代表大会常务委员会（2020年通过，2021年施行）. 中华人民共和国民法典，第一千零二十四条（名誉权）. http://www.mod.gov.cn/gfbw/qwfb/yw_214049/4866121.html?big=fan
  • 全国人民代表大会常务委员会. 中华人民共和国刑法，第二百四十六条（侮辱罪、诽谤罪）. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589827994.htm

限制与争议： 同事之间聊工作、聊行业、聊公开信息是正常社交，本条针对的是传播他人私事和负面评价；名誉权是否成立要个案判断，侮辱罪、诽谤罪多属告诉才处理、门槛较高。

7.别碰公司的钱和物：报销如实填，公司要求代收代付、刷单开票要拒绝

性价比：高

成本：钱=几块到几百 时间=极少 精力=极低

口径：职业寿命 / 职业自由

证据等级：B

说人话： 拿公司的笔和本子、多报几十块车费、用公司资源干私活，看着是小事，性质是占用公司财物；一旦被查，轻则被处理，重则涉及法律责任。

为什么 / 怎么做：

  • 报销如实填、没票不报，因公支出留好票据；公司设备、网络不用来干私活。
  • 虚报冒领、把私人消费混进报销，可能构成职务侵占罪。
  • 收受供应商回扣、好处费，以及公司要你刷单、虚开发票、代收代付，都可能违法，明确拒绝并留痕，必要时向合规、审计或监管渠道反映。

来源：

  • 全国人民代表大会常务委员会. 中华人民共和国刑法，第二百七十一条（职务侵占罪）. https://www.gjxfj.gov.cn/gjxfj/xxgk/fgwj/flfg/webinfo/2016/03/1460585589827994.htm
  • 全国人民代表大会常务委员会（2025年修订）. 中华人民共和国反不正当竞争法，第八条. http://www.npc.gov.cn/c2/c30834/202506/t20250627_446247.html

限制与争议： 职务侵占罪对数额较大设有立案门槛，以现行追诉标准和当地规定为准；公司对打印、耗材可能有默许的灰色地带，是否违规看制度和实际尺度；对公司有诉求走仲裁、投诉等合法途径。

一般性价比

8.对新人有耐心、别使唤新人干私活，带一带是低成本的人情投资

性价比：一般

成本：钱=0 时间=少 精力=低

口径：职业寿命 / 职业自由

证据等级：C

说人话： 新人刚来最需要有人指路，你花几分钟讲的，他记很久；职场圈子小，今天的新人可能是明天的同事、上级或合作伙伴。

为什么 / 怎么做：

  • 新人第一天主动介绍周边，告诉他怎么找信息、找谁问；基础问题耐心答，别甩脸色。
  • 不把取快递、买咖啡这类私事派给新人；新人被冤枉、确实不是大错时，就事论事帮着说一句。
  • 帮是情分、不帮是本分，量力而行，别把自己的活全搭进去。

来源： 相关的一般规定是《中华人民共和国民法典》对人格尊严与名誉权的保护：

  • 全国人民代表大会常务委员会（2020年通过，2021年施行）. 中华人民共和国民法典，第一百零九条、第一千零二十四条. http://www.mod.gov.cn/gfbw/qwfb/yw_214049/4866121.html?big=fan

限制与争议： 带人的回报是经验判断，教了徒弟饿死师傅的担心有一定道理，但真被替代说明自身可替代性高；职场里的言语侮辱、排挤多数达不到法律责任门槛。

本章小结： 这一章列的八件事有一个共同点：都是把成本很低的动作，做成了风险很高的事。在同事面前抱怨公司和领导，在朋友圈公开吐槽和晒摸鱼，在工位明目张胆地偷懒，当面顶撞领导，急着站队，传同事闲话，占公司小便宜，欺负新人。避开它们不需要额外投入，只需要动手前停一下：这句话发出去会不会被领导和客户看到；这件事的性质是休息还是违规；这个便宜是公司的还是自己的。遇到违法违规的指令，比如刷单、虚开发票、代收代付，要明确拒绝，并保留记录。据人力资源和社会保障部《2025年度人力资源和社会保障事业发展统计公报》，2025年全国各级劳动人事争议调解组织和仲裁机构共办理争议案件454.3万件、涉及劳动者472.1万人；很多麻烦，就是从不经意的一句话、一次站队、一笔小账开始的。把边界守住，比事后解释省力。
