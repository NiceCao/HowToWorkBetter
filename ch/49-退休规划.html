第49章 退休规划：别等老了才想钱的事

这一章解决的是：退休后能领多少养老金、大概差多少、现在该按什么顺序补上。按正文顺序看：先看懂养老金的计发公式，再算清最低缴费年限和法定退休年龄，然后用替代率估出缺口，最后依次比较企业年金、个人养老金和商业养老保险。整章给的是能照着算的方法，不替你做决定。 ---

极高性价比

1.先看懂养老金两个计发公式：基础养老金每缴1年计1%，个人账户按计发月数发

性价比：极高

成本：钱=0 时间=少 精力=低

口径：收入 / 职业寿命

证据等级：A

说人话： 工资里每月扣的养老保险，退休后能领多少有明确算法。看懂两个公式，就知道缴多少年、按什么基数缴，各自影响哪一块，也就能倒推自己该怎么缴。

为什么 / 怎么做： 基本养老金由两块组成。基础养老金＝（退休时当地上年度在岗职工月平均工资＋本人指数化月平均缴费工资）÷2×缴费年限×1%，缴费每满1年发1%，当地社平工资、缴费年限、缴费基数越高这一块越多。个人账户养老金＝个人账户累计储存额÷计发月数，个人缴费的8%计入个人账户，60岁退休按139个月、55岁170个月、50岁195个月计发。以社平工资8000元、一直按100%基数缴费、忽略利息为例，只算基础养老金，缴15年约1200元/月、缴30年约2400元/月，这是按公式做的假设测算，不是官方数据。

来源：

  • 国务院（2005）. 关于完善企业职工基本养老保险制度的决定（国发〔2005〕38号）. https://fgk.chinatax.gov.cn/zcfgk/c102440/c5193739/content.html
  • 吉林省人民政府（2018）. 个人账户养老金计发月数表. http://xxgk.jl.gov.cn/szf/gkml/201812/W020170717334413836105.pdf
  • 全国人民代表大会常务委员会（2018年修正）. 中华人民共和国社会保险法，第十五条. https://www.jingtai.gov.cn/zfxxgk/bmhxzxxgk/xzjdzfml/zlz/fdzdgknr/shbx/art/2023/art_ef315acaf7c24d36b996ccedb480b46b.html

限制与争议： 公式是全国统一的企业职工计发办法，但各地过渡性养老金和参数有差异，机关事业单位2014年10月后按另一套办法计发。本人指数化月平均缴费工资、个人账户记账利率、计发月数都随政策调整，任何估算都只是近似值；「高基数相对收益递减」说的是比例，绝对金额仍更高。

2.别把缴满15年当成终点，2030年起最低缴费年限每年提高6个月、最终到20年

性价比：极高

成本：钱=0（不仅不花钱，还决定了你退休后的收入） 时间=少 精力=低

口径：收入 / 职业寿命

证据等级：A

说人话： 缴满15年只是按月领基本养老金的最低门槛，不是「够了」，2030年起这个门槛还会逐年抬高。缴费年限越长，基础养老金和个人账户养老金都越高。

为什么 / 怎么做： 达到法定退休年龄且累计缴费满最低年限，才能按月领基本养老金，现行最低年限为15年；到龄没缴满的，可以延长缴费或一次性补足，也可以转入城乡居民养老保险。按2024年《国务院关于渐进式延迟法定退休年龄的办法》，从2030年1月1日起最低缴费年限由15年逐步提高到20年、每年提高6个月，2025年至2029年退休的仍为15年。仍以社平工资8000元、按100%基数、忽略利息为例，只算基础养老金，缴15年约1200元/月、缴30年约2400元/月；养老金每年调整还与缴费年限挂钩，年限长的涨得更多。

来源：

  • 全国人民代表大会常务委员会（2024）. 关于实施渐进式延迟法定退休年龄的决定（含国务院关于渐进式延迟法定退休年龄的办法，第二条）. https://www.gov.cn/yaowen/liebiao/202409/content_6974294.htm
  • 全国人民代表大会常务委员会（2018年修正）. 中华人民共和国社会保险法，第十六条. https://www.jingtai.gov.cn/zfxxgk/bmhxzxxgk/xzjdzfml/zlz/fdzdgknr/shbx/art/2023/art_ef315acaf7c24d36b996ccedb480b46b.html

限制与争议： 15年、20年是按月领职工养老金的门槛，不是「缴够就亏」或「缴够就赚」的分界，实际待遇仍按年限和基数计算。灵活就业人员按20%比例全部自费，延长缴费的现金流压力比在职职工大；是否划算还受寿命、健康和当地社平工资增长影响，无法用一个公式算准。

3.按出生年份算清法定退休年龄：男63岁、女55或58岁，还能弹性前后各3年

性价比：极高

成本：钱=0 时间=中 精力=中

口径：职业寿命 / 收入 / 职业自由

证据等级：A

说人话： 延迟退休已经落地。与其争论，不如先按出生年份算出自己哪一年退休，再据此安排缴费年限、职业寿命和储蓄。

为什么 / 怎么做： 自2025年1月1日起，用15年把男职工法定退休年龄从60岁延到63岁、原55岁女职工延到58岁、原50岁女职工延到55岁，节奏是男职工和原55岁女职工每4个月延迟1个月、原50岁女职工每2个月延迟1个月。缴满最低年限的可自愿弹性提前退休、最多提前3年（不低于原法定年龄男60岁、女55岁或50岁），与单位协商一致的可弹性延迟、最多延后3年。按出生年份看，1965年前出生的男职工、1970年前出生的女职工一般不受影响；1980年代及以后出生的基本完全到位，男到63岁、女干部到58岁、女工人到55岁，个人具体退休年月以人社部门公布的对照表为准。

来源：

  • 全国人民代表大会常务委员会（2024）. 关于实施渐进式延迟法定退休年龄的决定. https://www.gov.cn/yaowen/liebiao/202409/content_6974294.htm
  • 中国政府网（2024）. 顺应人口发展趋势 充分利用人力资源——四部门详解延迟退休办法. https://www.gov.cn/zhengce/202409/content_6974508.htm

限制与争议： 弹性提前退休会减少养老金，减发的比例和条件要看各地实施细则。出生年份与退休年龄的对应以官方对照表为准，这里给的是区间判断；特殊工种、高海拔地区等另有提前退休规定。

4.光靠基本养老金不够：企业职工替代率约四成，退休前先按公式估一次

性价比：极高

成本：钱=0 时间=少 精力=低

口径：收入 / 职业自由

证据等级：A

说人话： 基本养老保险只保基本，多数人退休后养老金低于退休前工资，缺口要么多缴，要么靠自己额外储备。先估出自己的替代率，再决定补多少。

为什么 / 怎么做： 养老金替代率＝退休后月养老金÷退休前月工资，替代率越高、退休前后落差越小；一项养老金金融白皮书估算，2024年我国城镇职工替代率约45%、城乡居民约30.6%（机构估算，非官方统计），人社部没有公开发布统一的替代率数字。缴费基数设60%保底、300%限高，超过上限的部分不计入，所以收入越高、替代率越低；国家统计局数据显示，2025年末我国60岁及以上人口32338万人、占23.0%，人口结构变化抬升了第一支柱的抚养压力。做法是先用官方测算工具估出自己大概能领多少，缺口用企业年金、个人养老金、储蓄或商业养老保险补。

来源：

  • 建信养老金、贝莱德建信理财（2025）. 中国养老金金融白皮书. https://www.blackrockccbwealth.com/uploads/files/31b73e026d8a758d2044c848bb1044b9.pdf
  • 国家统计局（2026）. 2025年人口数据解读（60岁及以上人口32338万人，占23.0%）. https://www.stats.gov.cn/xxgk/jd/sjjd2020/202601/t20260119_1962338.html

限制与争议： 替代率没有官方统一口径，用「养老金÷退休前工资」还是「÷社会平均工资」算，结果差别很大，这里采用前者。45%、30.6%是白皮书估算值、方法未完全公开，只能看量级；退休后支出结构会变（房贷、通勤、育儿支出减少，医疗护理增加），单看替代率不足以判断生活水平。

高性价比

5.公司有企业年金就参加，个人缴4%、单位配8%，单位部分相当于额外收入

性价比：高

成本：钱=个人工资的4%以内 时间=少 精力=低

口径：收入

证据等级：A

说人话： 企业年金和职业年金是第二支柱。有年金计划却不参加个人缴费，就拿不到单位配缴那笔，等于放弃一笔有税收优惠的补充养老钱。

为什么 / 怎么做： 企业年金由企业和职工共同缴费、基金完全积累、为每个参加职工建立个人账户，企业每年缴费不超过本企业职工工资总额的8%，单位和个人合计不超过12%（《企业年金办法》，人社部、财政部令第36号，2018年2月1日起施行）；职业年金面向机关事业单位，按个人缴4%、单位缴8%执行。单位缴费直接计入职工个人账户，以个人缴4%、单位缴8%为例，个人出1份、账户进3份，并在规定范围内税前扣除、投资收益暂不征税。2025年末全国17.79万户企业建立企业年金、参加职工3343万人（人社部2025年度统计公报）。

来源：

  • 人力资源社会保障部、财政部（2017）. 企业年金办法（第36号令），第十五条. https://www.gov.cn/gongbao/content/2018/content_5280588.htm
  • 人力资源社会保障部（2026）. 2025年度人力资源和社会保障事业发展统计公报. https://www.mohrss.gov.cn/SYrlzyhshbzb/zwgk/szrs/tjgb/202607/t20260716_580348.html

限制与争议： 企业年金覆盖面窄，2025年末参加职工3343万人，占城镇职工基本养老保险参保人数的比例很低，多数中小企业没有。部分企业设「归属期」，单位缴费要工作满一定年限才完全归个人，未满年限离职可能按比例扣回；年金领取环节要缴个税，且一般要到退休才能领，流动性差。

6.个税税率到20%以上再开个人养老金账户，每年1.2万元可在税前扣除

性价比：高

成本：钱=最多12000元/年 时间=少 精力=低

口径：收入 / 职业自由

证据等级：B

说人话： 个人养老金是自愿开立的封闭账户，核心好处是税收递延，省不省税取决于你的个税税率，税率低的人优惠有限。

为什么 / 怎么做： 自2024年12月15日起全国实施，参加城镇职工或城乡居民基本养老保险的劳动者均可参加，通过国家社会保险公共服务平台、电子社保卡、掌上12333App或符合规定的商业银行开立账户。税收优惠（财政部、税务总局2024年第21号公告）：缴费按12000元/年限额在综合所得或经营所得中据实扣除，投资收益暂不征个税，领取时不并入综合所得、单独按3%税率计税；资金封闭运行，达到领取条件、完全丧失劳动能力、出国（境）定居，或患重大疾病、领取失业保险金达到一定条件、正在领取最低生活保障金等情形可以领取。按税率算净省：个税税率10%的人每年约省（10%－3%）×12000≈840元，20%的人约省2040元，税率3%的人基本没有优惠。

来源：

  • 财政部、税务总局（2024）. 关于在全国范围实施个人养老金个人所得税优惠政策的公告（2024年第21号）. https://szs.mof.gov.cn/zhengcefabu/202412/t20241213_3949608.htm
  • 人力资源社会保障部等五部门（2024）. 关于全面实施个人养老金制度的通知（人社部发〔2024〕87号）. https://fgk.chinatax.gov.cn/zcfgk/c100013/c5236500/content.html

限制与争议： 全国统一的个人养老金开户和缴存数据未由主管部门定期公布，本条只按现行公告口径写。额度上限12000元/年，对高收入者补充作用有限；资金一般要到退休才能领取，年轻人锁定几十年、机会成本高，领取环节3%的税率和扣除限额未来是否调整也不确定。

7.买商业养老保险先算内部收益率，再看需不需要确定性和终身领取

性价比：高

成本：钱=按需（每年几千到几万不等） 时间=少 精力=中

口径：收入 / 职业自由

证据等级：B

说人话： 商业养老保险不是必需品，也不是高收益投资，它的价值在确定性和终身领取。买之前按合同现金流算清内部收益率，再判断自己需不需要这些功能。

为什么 / 怎么做： 常见的有年金险（约定年龄起按年或按月领取、金额写进合同）和增额终身寿险（现金价值逐年增长、可减保取现），核心是确定性与灵活性之间的取舍。判断要看清三点：收益看长期现金价值，监管没有公布统一的行业收益率数据，划不划算要自己按合同现金流算内部收益率，不能只看口头演示；流动性上中途退保按现金价值退还，早期退保往往低于已交保费；领取规则（何时领、领多少、领多久、能否退保、退保损失多少）要在投保前逐条问清。

来源：

  • 人力资源社会保障部等五部门（2024）. 关于全面实施个人养老金制度的通知（人社部发〔2024〕87号，商业养老保险列为个人养老金可投资产品之一）. https://fgk.chinatax.gov.cn/zcfgk/c100013/c5236500/content.html

限制与争议： 内部收益率随产品、缴费期、领取方式不同而不同，没有官方统一数据，购买前应以合同和利益演示为准。监管对销售误导有明确规范，但实践中仍有发生，演示收益不等于实际收益；保险的确定性和终身领取是存款、基金较难替代的功能，是否值得为此锁住资金因人而异。本节不推荐任何具体产品。

一般性价比

8.退休规划别只算钱，健康、兴趣、社交、技能这几类资本也要提前攒

性价比：一般

成本：钱=0 时间=中 精力=中

口径：职业自由 / 职业寿命

证据等级：B

说人话： 退休后的生活质量不只由钱决定。工作几十年突然闲下来，容易失去目标感和社交圈，趁早把钱以外的东西也准备起来。

为什么 / 怎么做： 退休生活大致看几个维度：财务上够用、不焦虑是前提；健康靠规律作息、适度运动、饮食均衡、定期体检、少烟酒；社交要主动维持朋友关系、参加社区活动，补上失去的职场社交场景；再有精神寄托（一门爱好、学点新东西、做点小副业）和居住照护安排（留大城市还是回老家、住原房还是换电梯房）。能提前攒的资本是健康、兴趣、人脉、技能和与家人的关系，退休后再补成本更高。所谓「财务独立、提前退休」要掂量两点：所需本金比想象的多，长期无事可能比上班更难受；半退休、做一份轻松且喜欢的工作是中间选项。

来源： 无。

限制与争议： 本条为经验判断：退休生活的重点因人而异，健康和社交对每个人的权重差别很大，没有标准答案。对不少人来说退休生活质量仍主要取决于经济状况，钱以外的东西是锦上添花，不能替代基本的经济保障；「提前退休」在中国还缺少成熟的本土研究，多数说法来自海外经验，适用性有限。

本章小结： 退休规划是把几件事按顺序做对：先看懂养老金的两个计发公式，知道自己每月缴的钱怎么变成退休后的收入；不要把缴满 15 年当成终点，2030 年起最低缴费年限每年提高 6 个月、逐步到 20 年，缴费年限比缴费基数更影响长期待遇；按出生年份算清自己的法定退休年龄（男 63 岁、女 55 或 58 岁，可弹性前后各 3 年）；再按公式估一次替代率——多数人的基本养老金低于退休前工资，缺口用企业年金、个人养老金和自己储备来补。企业年金个人缴 4%、单位配 8%，单位那部分相当于额外收入；个人养老金在个税税率到 20% 以上时更划算，每年 1.2 万元可税前扣除、领取时按 3% 计税；商业养老保险的价值在确定性和终身领取，买前先按合同现金流算内部收益率。钱以外，健康、兴趣、社交和技能也要提前攒。
