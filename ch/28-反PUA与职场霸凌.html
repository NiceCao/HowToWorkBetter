第28章 反PUA与职场霸凌：别让人把你PU傻了

职场里针对人格的贬低、骚扰、侮辱这些伤害，大多能对应到具体的法律条文，处理顺序是把行为对清楚、把证据留好、再选对渠道。本章八条按这个顺序排：前四条讲被反复否定或贬低时怎么记录、留痕，第五、六条讲侮辱、殴打、骚扰发生时先脱离现场、再报警或走劳动监察，第七条讲平时该存哪五类证据，第八条讲什么条件下值得走、被迫解除时怎么主张经济补偿。 ---

极高性价比

1.把「批评事」和「否定人」分开：每次贬低你个人的话，按日期、原话、在场的人记下来

性价比：极高

成本：钱=0 时间=少 精力=低

口径：职业寿命 / 时间精力

证据等级：B

说人话： 批评分两种：一种针对具体工作，指出哪里不行、怎么改，能照着改；一种直接贬低你这个人，反复出现会让人怀疑自己的能力。区分不看语气，看三点——说的是哪件事、给没给具体修改方向、有没有上升到人格。属于后一种的，当场把话说清楚，再按日期、原话、在场人记下来。

为什么 / 怎么做：

  • 识别：只给「不行」「你自己想」这类结论，不说哪里不行、怎么改；或评价指向人，比如「你连这个都做不好」，很少落到具体工作。
  • 留痕：按日期记下原话、场合和在场的人，先存在自己的私人设备上；对方发的消息、邮件留原件，不只留截图。
  • 渠道：先走单位内部申诉、工会或人力资源渠道，书面反映并留提交记录；涉及公然侮辱、威胁人身安全的，报警。

来源：

  • 全国人民代表大会（2020）. 中华人民共和国民法典（第九百九十条、第九百九十五条）. http://www.npc.gov.cn/npc/c30834/202006/75ba6483b8344591abd07917e1d25cc8.shtml
  • 全国人民代表大会常务委员会（2025年修订，2026年1月1日施行）. 中华人民共和国治安管理处罚法（第五十条）. http://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446254.html

限制与争议： 说话直接、要求高，和针对人格的贬低之间没有法定分界线，要结合长期表现判断，不必凭单次感受下结论；职场心理伤害目前我国没有专门的诊断或法律定义，本条给的是可记录、可举证的观察方法。

2.反馈只说「不行」却不给具体修改要求的，先把每次要求与反馈留痕，再走书面内部反馈

性价比：极高

成本：钱=0 时间=少 精力=低

口径：职业寿命 / 时间精力

证据等级：B

说人话： 有的反馈只给否定结论，让人反复返工又不知道错在哪。把每次要求、修改和结果逐条对起来，就能看出问题出在事上、流程上，还是标准反复变化；留痕之后再走内部书面渠道，比当场争执更容易留下有效记录。

为什么 / 怎么做：

  • 识别：要求提出后又被否认、同一件事标准反复变；或只评价人（「你不用心」），不指出具体哪一项要改。
  • 留痕：逐条对应记下任务要求、交付时间和每次修改反馈；邮件、聊天记录留带时间戳的原件，另存反映工作量与产出的记录。
  • 渠道：先走单位内部书面反馈；绩效考核有争议的，按劳动合同和单位制度申请复核；进入劳动仲裁的，主张由提出方举证。

来源：

  • 全国人民代表大会常务委员会（2007）. 中华人民共和国劳动争议调解仲裁法（第六条）. http://www.npc.gov.cn/npc/c12435/200712/t20071229_425587.htm

限制与争议： 反馈方式好坏属管理和沟通范畴，多数情形对不上具体条文，能走的主要是内部复核、调岗和换工作；把「反复改稿」直接当侵害站不住脚，记录的意义是分清责任，不是给谁定性。

3.有人用恩情、团队精神压你答应违规的事，当场说明拒绝并把原话留痕

性价比：极高

成本：钱=0 时间=少 精力=中

口径：职业自由 / 时间精力

证据等级：B

说人话： 「恩情」「团队精神」「以后给你好处」这类说法，常被用来让人答应本不该答应的事。判断不看对方语气，看要求本身有没有越出法律、合同和岗位职责；越界的当场说明并留痕，不必当场争吵。

为什么 / 怎么做：

  • 识别：用过去的帮助、领导的难处、同事都在加班来要求你让出法定权益；或让你做违反规定、法律的事，并用情分施压。
  • 留痕：记下要求的原话、提出时间和在场的人；重要要求用消息或邮件回复确认，涉及承诺的要求写明岗位、金额和时间。
  • 渠道：以暴力、威胁或非法限制人身自由手段强迫劳动的，可立即解除劳动合同、不需事先告知并主张经济补偿，同时报警。

来源：

  • 全国人民代表大会常务委员会（2012）. 中华人民共和国劳动合同法（第三十八条、第四十六条）. http://www.npc.gov.cn/npc/c12435/201212/t20121228_1877413.htm
  • 全国人民代表大会常务委员会（2025年修订，2026年1月1日施行）. 中华人民共和国治安管理处罚法（第四十七条）. http://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446254.html

限制与争议： 领导为团队争取利益、职场本来就要承担压力，这和强迫劳动有本质区别，不宜把一切「不容易」都当成施压；是否构成强迫劳动，看有没有暴力、威胁或限制人身自由。「承诺一定要兑现」属经验判断，法律只在特定情形下支持。

4.对方否认说过的承诺时，当场用邮件或消息确认一遍，把记录存档

性价比：极高

成本：钱=0 时间=少 精力=中

口径：职业寿命

证据等级：A

说人话： 有人会否认自己说过的话，让你怀疑自己的记忆。稳妥的做法是把重要沟通落成文字：口头谈完立刻用邮件或消息复述一遍请对方确认，出现分歧时按时间线摆记录，而不是靠回忆争论；这些记录在劳动维权时也能当证据用。

为什么 / 怎么做：

  • 识别：反复否认说过的话、声称「我没那个意思」；或对同一件事前后说法不一致，且间隔不长。
  • 确认：重要决定的事项、时间、对方原话，当天写成消息或邮件请对方确认。
  • 整理：邮件、聊天记录留原件，注明时间和收发双方；按时间线列一份「什么时间、谁说了什么、对应哪份记录」，仲裁或诉讼时提交。

来源：

  • 全国人民代表大会（2020）. 中华人民共和国民法典（第四百六十九条）. http://www.npc.gov.cn/npc/c30834/202006/75ba6483b8344591abd07917e1d25cc8.shtml
  • 全国人民代表大会常务委员会（2007）. 中华人民共和国劳动争议调解仲裁法（第六条）. http://www.npc.gov.cn/npc/c12435/200712/t20071229_425587.htm

限制与争议： 「对方在故意扭曲你的认知」是一种推断，除非有多次相互矛盾的记录，否则难以证明；有人确实记性差或表述含糊，未必有意为之。本条给的是留存和核对的做法，不替代心理或法律专业人士的意见。

高性价比

5.遇到当众侮辱、体罚、殴打、非法搜查或拘禁时，先脱离现场再报警，同时向劳动监察投诉

性价比：高

成本：钱=0 时间=中 精力=中

口径：职业寿命 / 收入

证据等级：A

说人话： 当众侮辱、体罚、殴打、非法搜查、限制人身自由这些行为，都有明确的法律条文对应，属于治安和法律问题。处理顺序是先保证人身安全、脱离现场，再固定证据，然后报警并走劳动监察。

为什么 / 怎么做：

  • 报警：殴打、非法限制人身自由、非法搜查身体、以暴力威胁手段强迫劳动的，报警 110，由公安机关依治安管理处罚法处理，构成犯罪的追刑责。
  • 投诉：用人单位侮辱、体罚、殴打、非法搜查或者拘禁劳动者的，依法给予行政处罚、造成损害要赔偿，向当地人力资源社会保障部门投诉。
  • 留证：伤情照片、就医和验伤记录、现场视频音频、在场人联系方式、对方发来的辱骂威胁消息原件。

来源：

  • 全国人民代表大会常务委员会（2025年修订，2026年1月1日施行）. 中华人民共和国治安管理处罚法（第四十七条、第五十条、第五十一条）. http://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446254.html
  • 全国人民代表大会常务委员会（2012）. 中华人民共和国劳动合同法（第三十八条、第八十八条）. http://www.npc.gov.cn/npc/c12435/201212/t20121228_1877413.htm

限制与争议： 「职场霸凌」不是我国法律里的独立概念，要落到具体行为上再对号；冷落、排挤、刁难这类软性行为，多数对不上具体条文，能走的主要是内部投诉、调岗和换工作。具体定性和处理结果由公安机关或裁审机关认定。

6.按行为性质选渠道：侮辱恐吓报警、克扣工资找劳动监察、争议去仲裁、人格权被侵害可起诉

性价比：高

成本：钱=0 时间=中 精力=中

口径：时间精力 / 职业寿命

证据等级：B

说人话： 应对职场伤害，先给行为归个类，再走对应渠道，比笼统地「投诉」更快。四类渠道各管一段：治安问题找公安，用工违法找劳动监察，劳动关系争议找仲裁，人格权益受到侵害可以向法院起诉；几条渠道可以并行。

为什么 / 怎么做：

  • 治安问题，如公然侮辱、威胁他人人身安全、殴打、非法限制人身自由 → 报警 110。
  • 用工违法，如克扣或拖欠工资、不缴社会保险、违法超时加班 → 用人单位所在地人力资源社会保障部门；劳动关系争议，如解除劳动合同、经济补偿、绩效与调岗争议 → 劳动人事争议仲裁委员会。
  • 人格权益，如性骚扰、名誉受损、隐私被泄露 → 向人民法院提起民事诉讼，性骚扰的受害人可以报案，也可以依法请求行为人承担民事责任。

来源：

  • 全国人民代表大会常务委员会（2025年修订，2026年1月1日施行）. 中华人民共和国治安管理处罚法（第四十七条、第五十条）. http://www.npc.gov.cn/npc/c2/c30834/202506/t20250627_446254.html
  • 国务院（2004）. 劳动保障监察条例（第九条、第十条）. https://guangdong.chinatax.gov.cn/gdsw/zjfg/2026-05/26/content_daac28e31053441c81cb0790fdf65f70.shtml
  • 全国人民代表大会（2020）. 中华人民共和国民法典（第九百九十条、第一千零一十条）. http://www.npc.gov.cn/npc/c30834/202006/75ba6483b8344591abd07917e1d25cc8.shtml

限制与争议： 四条渠道的受理条件和时限不同，同一起纠纷未必都能立上，先按行为性质选最贴切的一条为主，其余作补充；用人单位负有预防和制止性骚扰的义务，投诉后有关单位和国家机关应当及时处理并书面告知处理结果。

7.从现在起按时间线存五类证据：沟通记录、工作成果、考勤加班、工资合同、辱骂或骚扰的原始记录

性价比：高

成本：钱=0 时间=少 精力=低

口径：收入 / 职业寿命

证据等级：A

说人话： 无论打算留下、离开还是维权，证据决定你能谈到什么条件。按时间线把材料存好，比一堆零散截图更有用——发生劳动争议时，当事人对自己提出的主张有责任提供证据。

为什么 / 怎么做：

  • 该开始存的情形：被反复否定、被克扣报酬、被要求做违规的事、遭遇骚扰或威胁。
  • 五类材料：沟通记录，包括消息、邮件、会议纪要原件；工作成果，包括方案、报告、客户反馈、绩效结果，留版本和时间；考勤与加班，包括打卡记录、加班审批、相关消息和交通记录；工资与合同，包括劳动合同、工资条或银行流水、社会保险缴纳记录、调薪与晋升通知；辱骂或骚扰，包括消息邮件原件、录音录像、在场人。
  • 用法：向单位内部反映，向劳动监察或劳动仲裁提交，向法院起诉；原件优先、多处备份，不要只放在单位的设备和账号里。

来源：

  • 全国人民代表大会常务委员会（2007）. 中华人民共和国劳动争议调解仲裁法（第六条）. http://www.npc.gov.cn/npc/c12435/200712/t20071229_425587.htm

限制与争议： 录音能否被采信，各地尺度不一，擅自录制他人隐私内容可能不被采信，甚至反过来构成侵权，取证前建议咨询当地律师或法律援助机构，对方知情的公开录制风险相对较低；证据只能增加你的筹码，不保证结果。

一般性价比

8.用健康、晋升、法律红线三个条件决定走留，离开时按劳动合同法主张被迫解除

性价比：一般

成本：钱=高（可能损失收入/机会成本） 时间=中 精力=高

口径：职业寿命 / 收入 / 职业自由

证据等级：B

说人话： 走还是留，可以拆成几条能核对的条件。先看三个硬条件，再算留下的收益和代价；决定离开时，区分是主动辞职还是被迫解除，直接影响能不能拿到经济补偿。

为什么 / 怎么做：

  • 三个条件：健康上，是否出现与工作环境相关的持续失眠、情绪或躯体症状，出现自伤念头先求助，全国心理援助热线 12356；发展上，绩效和晋升是否因与工作表现无关的原因被长期封死；法律上，是否触及殴打、性骚扰、非法限制人身自由、恶意欠薪等红线。
  • 可暂留：把它当过渡期，同时找工作或备考，给自己设一个明确期限；或平台和项目确实能积累能力，且不涉及法律红线。
  • 离开时：尽量找到下家再走，核对工资、奖金、年假、报销是否结清；因单位强迫劳动等违法情形不愿继续的，依劳动合同法第三十八条解除并主张经济补偿。解除与经济补偿的争议申请劳动仲裁，恶意欠薪、不缴社会保险的向当地人力资源社会保障部门投诉。

来源：

  • 全国人民代表大会常务委员会（2012）. 中华人民共和国劳动合同法（第三十八条、第四十六条）. http://www.npc.gov.cn/npc/c12435/201212/t20121228_1877413.htm
  • 国家卫生健康委员会（2024）. 国家卫生健康委关于应用「12356」全国统一心理援助热线电话号码的通知（国卫医政函〔2024〕259号）. https://www.gov.cn/zhengce/zhengceku/202412/content_6994470.htm

限制与争议： 走还是留取决于个人经济状况和行业周期，没有统一答案，别人给的判断只能当参考；以「被迫解除」主张经济补偿需要证据支撑，例如强迫劳动、欠薪等情形，单方面说不愿意并不成立。心理症状的判断以专业医疗诊断为准，本条不替代就医建议。

本章小结： 职场伤害可以按行为对号、按渠道处理，不必靠情绪判断。可核对的要点：①反复针对人格、只给否定结论却不给具体要求的反馈，先按日期、原话和在场人记录；②遇到当众侮辱、殴打、体罚、非法搜查或限制人身自由，报警并投诉到劳动监察；③性骚扰可依民法典第一千零一十条请求行为人承担民事责任，用人单位负有预防、受理投诉、调查处置的义务，投诉后有关单位和国家机关应当及时处理并书面告知处理结果；④沟通记录、工作成果、考勤加班、工资合同和辱骂骚扰的原始记录，按时间线存好；⑤走留可以按健康、发展、法律红线三个条件判断，离开时区分主动辞职与被迫解除，被迫解除依劳动合同法第三十八条主张经济补偿。多条官方渠道可以并行，先保证人身安全，再固定证据，最后选择渠道。
