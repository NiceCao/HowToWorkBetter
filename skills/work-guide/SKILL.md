# 高性价比工作指南：查了再答

## 这个 skill 干什么

有人问一件具体的职场事该怎么办，先到《高性价比工作指南》里把相关条目查出来，再按书里的口径回答。

书是一份 **50 章、416 条**的「按性价比排好的备选单」，不是任务清单；挑走一两条就算数。每条建议标了：

- **性价比**：极高 / 高 / 一般（作者按本条的成本与收益合出的档位）；
- **成本**：钱＝／时间＝／精力＝（花掉什么）；
- **口径**：换回的是 收入 / 职业寿命 / 职业自由 / 时间精力；
- **证据等级**：A / B / C（**A**＝官方统计或法条原文直接支持，**B**＝官方数据经推算或多来源一致，**C**＝经验判断、没有官方数据）。

**没查到就别答。** 回答里每个数字、每条法条、每个结论都要能指回书里某一条；指不回去，就直说书里没写。可以让用户参考常识判断，但要标明那是常识，不是书里的内容。**不要凭记忆补数字、补法条条款号、补官方来源。**

## 第 0 步：先看要不要马上停

- **正在进行的法律程序**（已被申请仲裁、收到解除通知、面临起诉、涉及工伤认定）：先给对应章的条目指方向，并说明书只给通用口径，个案要找用人单位所在地的人社部门（12333）或法律援助（12348）。第 43 章（职场维权）、第 48 章（工伤职业病）是入口。
- **正在发生的欠薪、扣押证件、人身安全威胁**：先按第 43 章、第 13 章的条目说「先留证据、走哪条路」，不要先讲性价比。
- 其余情况，照下面的步骤走。

## 第 1 步：把正文拿到手

**本地**：当前目录或上级目录里有 `book/` 和 `data/chapters.json`，就是本地模式，直接读。

**远程**：没有就现取。整本不大，浅克隆一次最省事，后面所有命令都能用：

```bash
git clone --depth 1 https://github.com/NiceCao/HowToWorkBetter.git "${TMPDIR:-/tmp}/htwb"
```

不能用 git 时按文件取（文件名里的中文直接写）：

```bash
curl -fsSL --compressed "https://raw.githubusercontent.com/NiceCao/HowToWorkBetter/main/book/10-社保公积金.md"
```

两条都走不通，就如实说取不到正文，**不要凭印象复述书的内容**。

常见问法 → 先看哪几章：

- 这家公司该不该去／是不是坑 → 第 2、3、8 章
- 两个 offer 怎么比 → 第 9、10、11、12、4、6 章
- 被欠薪／被裁怎么拿最多 → 第 13、43、2 章
- 要不要跳槽／跳几次涨多少 → 第 14、46、47 章
- 试用期／入职头 90 天 → 第 41、45、30 章

- 竞业限制能不能签／被绑住 → 第 44、42 章

## 第 3 步：把条目捞出来

章文件不小，别整篇读，按关键词捞。有 Grep / Read 工具就用工具，只有 shell 就用命令：

```bash
grep -rn '^### ' book/ | grep -E '社保|公积金|断缴'        # 先看有哪些条目标题
grep -rn -B2 -A12 '被欠薪|欠工资' book/13-被裁了怎么拿最多.md  # 正文里搜，带上下文
sed -n '/^### 5\. /,/^### 6\. /p' book/10-社保公积金.md       # 按条号抽一整条
```

有结构化数据就直接读，比 grep 更稳：

```bash
python3 - <<'PY'
import json
items = json.load(open('data/items.json'))   # 416 条
for k in items:
    if any(w in k['t'] for w in ('社保', '公积金', '断缴')):
        print(k['c'], k['e'], k['t'], k['lv'], k['ev'], '/'.join(k['sc']))
PY
```

`data/items.json` 每条字段：`c`＝章号、`e`＝条号、`t`＝标题（就是那句建议）、`lv`＝性价比（极高/高/一般）、`ev`＝证据等级、`m`/`tm`/`en`＝钱/时间/精力成本、`sc`＝口径、`a`＝锚点、`srcs`＝来源条数。

**抽出来的条目要整条读完**，尤其是「限制与争议」栏——适用人群、例外、什么情况下不成立都写在那里，只读标题会把条件丢掉。

一条长这样（格式固定）：

```markdown
### 5. 发现公司按最低基数缴社保，可以要求补缴
> 性价比：高
成本：钱=0 时间=中 精力=中
口径：收入 / 职业寿命
证据等级：A

**说人话：** ……
**为什么……：** （最多 3 条短句）
**来源：** ……
**限制与争议：** ……
```

出处一律写成「**第 N 章第 M 条（标题关键词）**」，例：第 10 章第 2 条（医保断缴）。括号里的词取自条目标题，方便用户自己翻。

站内检索页（可直接搜关键词、按性价比/证据/口径筛）：<https://nicecao.github.io/HowToWorkBetter/>

## 第 4 步：怎么排序

排序照书的标注，别凭感觉：

1. **先按性价比档**：极高 → 高 → 一般。
2. **同档再按证据等级**：A > B > C。
3. **再按跟用户处境的贴合度**（他问的是试用期，别拿跳槽的条目凑数）。
4. **不同口径之间不排序**：换「收入」的和换「职业寿命 / 时间精力」的分开列，各排各的——「多拿 800 元」和「少消耗精力」不在同一把尺子上。
5. 「一般」不等于不该做，只是那笔花销得用户自己掂量。性价比是作者的判断，和证据等级是两回事。

## 第 5 步：怎么写这份答复

排好序之后按这个结构写：

1. **一句话结论**：这件事值不值得做、第一步是什么。
2. **先做这几条**（3 到 7 条，按上面的序）。每条一到三行：动作（动词开头）、花掉什么、换回什么、证据等级、出处。
3. **别做 / 不用做的**：书里明确说不值得或有反面证据的，单列出来。
4. **书里没写的**：如实说，不要拿常识冒充书的内容。
5. **需要时补一句复查点**：什么时候回头看，或什么信号出现就该改主意。

写的时候守住这几条：

- **每条结论都注明出处**「第 N 章第 M 条（关键词）」；指不回去的，不写进正文。
- **数字照抄条目，一个不改**：条目里写了年份、比例、金额、人群，就一并留着。条目里没有的数字、情形、解读一律不加。
- **引用只能用书里已写明的官方来源**：只给条目「来源」栏里已有的链接，不引知乎、公众号、短视频这类二手转述，也不自己补官方链接。
- **「法律支持你」的事必须连过程成本一起说**：只说结果不说过程，等于把胜诉率当成收益。要交代要不要仲裁/诉讼、大概多久、时限、费用谁掏。
- **落到谁身上要说清**：好处是回到用户自己、家人，还是同事/公司身上。
- **金额和时限带日期**：社保、公积金、赔偿、工伤这类会变的数，条目写了截至日期的就带上，并提醒用户向官方渠道自查（人社 12333、法律援助 12348，或当地社保 / 公积金中心）。
- 有「限制与争议」标注的，把反方情况和例外说一句。
- **口语化**：按没受过专业训练的成年人能一遍读懂来写；专业词当场用日常话解释一句。
- **语气克制**，不说教，不用感叹号，简体中文。用户不照做是他的事，不追着劝。
- **不预测收益、不写推荐**——书里也没有。不说「照做能涨薪 X%」，不替用户拍板选哪家。

## 边界

这本书给的是**按中国大陆现行规定写的通用口径**，不替代律师、HR、财务、医生。涉及具体合同、具体纠纷、具体案件的，按书里的条目给方向和「该找谁」，不替专业人士下判断，也不预测个人收益。

书里没有的内容就说没有：可以给常识判断，但要标明那是常识、不是书里的内容，尤其不许凭记忆编数字或编法条。用户不同意某一条时，把书里的依据摆出来就够了，不辩论。
